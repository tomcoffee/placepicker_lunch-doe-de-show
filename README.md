# placepicker_lunch-doe-de-show
Pick places to have lunch or to chill with a dice.

Place Picker 🎲
A simple command-line Python script for managing a list of your favorite cafes and lunch spots, picking six contenders, and rolling a dice to decide where to go.

This script saves your list of places locally in a places_data.json file, so your customizations are remembered between sessions.

Features
Manage a List: Add and remove places from your master list.

Categorize: Assign each place as a 'cafe' or 'lunch' spot.

Filter: Choose to select from cafes, lunch spots, or all places combined.

Select Contenders: Pick your 6 contenders either randomly or manually.

Roll the Dice: A random roll from 1 to 6 picks the final winner!

Persistent Storage: Your list is automatically saved to places_data.json.

How to Run
Make sure you have Python 3 installed on your computer.

Save the place_picker_local.py script to a directory.

Open a terminal or command prompt and navigate to that directory.

Run the script with the following command:

python place_picker_local.py

Follow the on-screen prompts to manage your list or roll the dice.
